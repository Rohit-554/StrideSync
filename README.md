## Getting Started

1. Open the project in Android Studio or IntelliJ IDEA
2. Sync Gradle
3. Run `./gradlew :androidApp:assembleDebug` to build the Android app

## Manual Server Start

1. Ensure Docker is running.
2. Start the backend with `./scripts/start-server.sh`.

The server reads `DB_URL`, `DB_USER`, `DB_PASSWORD`, `JWT_SECRET`, and related values from environment variables first, then falls back to the repo-root `.env` file for manual and IDE launches.

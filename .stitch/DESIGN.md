# StrideSync Design System

## App
- Platform: Mobile (Android + iOS)
- Category: Fitness tracking + social

## Colors
- Primary: #FC4C02 (Strava orange)
- Background: #111318 (deep charcoal)
- Surface: #1C1F26 (elevated card)
- Surface2: #252830 (input fields)
- Text primary: #F0F0F0 (warm white)
- Text secondary: #9BA3B2 (soft gray)
- Success: #3ECF8E
- Error: #F56565
- Active GPS: #FC4C02 with glow halo

## Typography
- Headings: Bold rounded sans-serif, large
- Body: Regular weight, generous line height
- Stats/Numbers: Extra bold, tabular figures
- Labels: Small caps, tracked, muted gray

## Components
- Buttons: Fully pill-shaped, 56dp height
- Cards: 16dp corner radius, dark elevated surface
- Inputs: Dark elevated, orange active border, floating label
- Bottom nav: Dark surface, orange active indicator pill
- Map tiles: Dark satellite style, orange route polyline
- Stat blocks: Large number + small gray label

## Mood
Premium, athletic, motivating. Like a coach's dashboard.
Dark-first. Energetic but not garish. Strava-inspired.

# Deploying the StrideSync Backend (Render + Neon, free tier)

The Ktor server runs on **Render** (free web service, Docker) and talks to a
**Neon** serverless Postgres database (free, persistent). Both require no credit card.

## 1. Create the database on Neon

1. Sign up at https://neon.tech and create a project (pick a region near Render's `oregon`).
2. Open the project's **Connection Details** and copy the connection string. It looks like:

   ```
   postgresql://alex:AbC123@ep-cool-rain-12345.us-west-2.aws.neon.tech/stridesync?sslmode=require
   ```

3. Translate it into the three env vars the server expects. Note the JDBC prefix
   and that `sslmode=require` is mandatory for Neon:

   | Env var       | Value from the Neon string                                                        |
   |---------------|-----------------------------------------------------------------------------------|
   | `DB_URL`      | `jdbc:postgresql://ep-cool-rain-12345.us-west-2.aws.neon.tech/stridesync?sslmode=require` |
   | `DB_USER`     | `alex`                                                                            |
   | `DB_PASSWORD` | `AbC123`                                                                          |

   (`DB_URL` = `jdbc:` + everything from `postgresql://` onward, **minus** the
   `user:password@` part, **keeping** `?sslmode=require`.)

## 2. Deploy the server on Render

1. Push this repo to GitHub.
2. In Render: **New → Blueprint**, select the repo. Render reads `render.yaml`.
3. When prompted, fill the secrets marked `sync: false`:
   - `DB_URL`, `DB_USER`, `DB_PASSWORD` from step 1.
   - `JWT_SECRET` is auto-generated by Render — leave it.
4. Click **Apply**. Render builds `server/Dockerfile` and deploys.

The service comes up at `https://stridesync-server.onrender.com` (name may vary).
Render polls `/health` to confirm it's live.

## 3. Point the app at the deployed server

Update the client base URL (currently `10.0.2.2:8080` / `localhost:8080`) to the
Render URL. WebSocket tracking must use `wss://` (Render terminates TLS):

- REST:      `https://stridesync-server.onrender.com`
- WebSocket: `wss://stridesync-server.onrender.com`

## Free-tier caveats

- **Cold starts:** the free Render service sleeps after 15 min idle and takes
  ~1 min to wake on the next request. Fine for demo, not for production.
- **Neon scale-to-zero:** the DB also suspends when idle; first query after a
  pause adds a short delay.
- **Storage:** Neon free gives 0.5 GB — plenty for GPS/activity data while testing.

## Local development is unchanged

`docker-compose up` still runs Postgres + server + pgAdmin locally using `.env`.
The only change is that the server now honors a `PORT` env var when set,
defaulting to `8080`.
